# SC8802电池充电器
双向可充电和放电，最高支持30V电池电压和输入输出电压，用于给笔记本电池，电动工具电池等内部没有电压转换模块的电池组充电，可以当USB移动电源，也可以作为储能单元
## 目标特征
- 与[SmartBattery协议](https://en.wikipedia.org/wiki/Smart_Battery_System)电池通信
- 使用[USB PD协议](https://en.wikipedia.org/wiki/USB_hardware#USB_Power_Delivery)连接外部设备进行充电和放电
- 可调电源
- 支持使用太阳能等功率受限电源MPPT充电
- 与电源管理中心通信，并接受调度
